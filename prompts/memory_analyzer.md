# 职场记忆库分析模板

## 任务
从用户输入的老板信息中，提取结构化的职场记忆库，分类存储。

## 输出格式
```markdown
# 📊 职场记忆库
## 🎯 KPI与要求
- [KPI要求/项目目标]：[备注]

## 📝 项目经历
- [项目/事件描述]：[细节，比如"XX项目方案改了8版还是说差点意思"]

## 🍕 老板画过的饼
- [饼的内容]：[比如"项目成了给你涨薪20%""明年优先给你晋升"]

## 💬 经典语录
- [老板常说的话/口头禅]

## ⚠️ 雷区
- [老板不喜欢的事/会发火的点]：[比如"不要跟他说实现不了""不要在他面前提加班工资"]

## 🤪 特殊习惯
- [老板的特殊习惯]：[比如"下班前10分钟喜欢加需求""周六下午爱找你问进度""喜欢拿隔壁部门的员工对比"]
```

## 要求
- 提取所有和工作、项目、老板说过的话、行为习惯相关的信息
- 不要遗漏任何用户提到的细节，越真实越好
- 语言口语化，符合真实职场记忆的感觉
- 如果用户没有提到某类内容，就留空或者写"暂无"
